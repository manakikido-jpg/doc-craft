# LP制作ワークフロー

## 概要

コピーライティング（新PASONA）×デザイン原則（frontend-design）×景表法チェックを
一本のワークフローに統合したLP制作スキル。コーチング・キャリア支援の高単価サービスに特化。

---

## Step 1: ヒアリング（必ず最初に確認）

以下が未定義なら聞く。1つでも揃えば先に進める。

| 確認項目 | 例 |
|---|---|
| LPの目的（パターン） | 体験セッション獲得 / セミナー集客 / 継続契約直接獲得 |
| ターゲット | 転職検討中の30代会社員、副業を始めたい20代など |
| 訴求する感情的ベネフィット | 「転職への不安が消える」「自分の市場価値が分かる」 |
| CTA（行動） | 無料診断申込 / LINE登録 / セミナー予約 / 面談予約 |
| 実績・社会的証明 | 支援人数、資格、受講者の声（あれば） |
| 禁止・NG表現 | 景表法上の注意事項（成果保証・断定・No.1等） |

---

## Step 2: 構成設計（新PASONA × 目的パターン）

`references/lp-frameworks.md` の型から目的に合ったものを選び、セクション一覧を作る。

**標準セクション順（キャリア支援LP）:**

1. **ファーストビュー** — キャッチコピー + サブコピー + CTA + ビジュアル方針
2. **共感（Problem × Affinity）** — ターゲットが感じている悩みに言語化して共鳴
3. **解決策提示（Solution）** — サービスの特徴・差別化ポイント（3つ以内に絞る）
4. **証拠・実績** — 支援実績・資格・受講者の声（景表法チェック必須）
5. **サービス詳細（Offer）** — 内容・所要時間・料金・提供フロー
6. **絞込み（Narrow down）** — 対象者明示・受付枠・期間限定（不安煽りは禁止）
7. **CTA + フォーム** — 行動を促す文言 + フォームシンプル化
8. **FAQ** — 申込みを阻む疑問を先回り解消
9. **最終CTA** — 再度、CTAボタン

---

## Step 3: コピーライティング

各セクションのコピーを書く。以下の制約を必ず守る。

### コピー品質チェックリスト

- [ ] ファーストビューのキャッチコピーは3秒で「自分ごと」と感じられるか
- [ ] ベネフィット（得られること）をフィーチャー（機能・特徴）より先に書いているか
- [ ] 「誰でも」「必ず」「保証」「〇〇No.1」は使っていないか（景表法）
- [ ] CTAボタンのテキストは具体的行動を示しているか（「詳しく見る」は禁止）
- [ ] 社会的証明に「〇名支援」等の数字を入れているか（根拠のある数字のみ）

---

## Step 4: デザイン指示（frontend-design 原則を適用）

コーディング実装または外注時に渡すデザイン仕様書を出力する。
詳細原則 → `references/design-principles.md`

**出力フォーマット:**

```
【カラーパレット】
Primary: #______（メインカラー・ブランドカラー）
Accent:  #______（CTA・強調）
Base:    #______（背景）
Text:    #______（本文）
Muted:   #______（補足・キャプション）

【タイポグラフィ】
Display: ______ （キャッチコピー・見出し用。個性的な書体を選ぶ）
Body:    ______ （本文。読みやすさ最優先）
UI:      ______ （ボタン・ラベル）

【レイアウト方針】
ファーストビュー: ______
セクション余白: ______
CTA ボタン: ______（色・形・テキスト）

【禁止事項（このLPで避けるもの）】
- ______
```

---

## Step 5: 景表法・コンプライアンス最終チェック

`sns-post-workflow/references/compliance.md` に準じて全コピーをチェック。
または DocCraft の「公開前チェック」スキルに本文を貼り付けて自動監査を実行。

- 成果を断定する表現がないか（「〇ヶ月で転職できる」等）
- 体験談・口コミを使う場合、個人の感想であることを明記しているか
- 無料・初回限定等の条件を正確に記載しているか

---

## Gotchas（必読）

- ⚠️ ファーストビューのコピーは「このページ = 自分の問題を解決できる場所」と3秒以内に伝えること。
  一般的な価値提供では離脱する
- ⚠️ 「誰でも・必ず・保証」は景表法違反リスク。キャリア支援文脈では特に厳禁
- ⚠️ CTAは最低3箇所（ファーストビュー・中盤・最下部）設置する
- ⚠️ FAQ は「申込みを阻む疑問」を回答するもの。サービス説明の繰り返しにしない
- ⚠️ デザインは「AIっぽい定番」を避ける。
  禁止: warm cream + serif terracotta / near-black + acid-green / 密度の高い新聞風レイアウト
