# LPコピーフレームワーク

## 新PASONA（キャリア支援LP向け推奨）

高単価・信頼構築型サービス（コーチング・キャリア相談）に最適。長文LPに向く。

| ステップ | 意味 | キャリア支援での具体例 |
|---|---|---|
| Problem | 問題 | 「転職すべきか分からないまま3年経った」 |
| Affinity | 親近感 | 「その気持ち、よく分かります」（共感・同じ立場から） |
| Solution | 解決策 | 「国家資格キャリアコンサルタントが市場価値を客観的に診断」 |
| Offer | 提案 | 無料診断の内容・所要時間・得られるもの |
| Narrow down | 絞込み | 「月10名限定」「今月末まで」（不安を煽る表現は禁止） |
| Action | 行動 | 「今すぐ無料で診断を受ける」 |

## AIDA（短文・広告・SNS向け）

バナー広告・SNS投稿・メルマガ件名など、限られたスペースに使う。

| ステップ | 意味 |
|---|---|
| Attention | 注目を引く（問いかけ・数字・意外性） |
| Interest | 興味・関心（ベネフィットを示す） |
| Desire | 欲求（「自分もそうなりたい」） |
| Action | 行動（CTAリンク） |

---

## PASBECONA（長文セールスレター・高単価）

コーチング・継続契約など説明量が多い高単価サービス向け。

P → A（共感）→ S → B（ベネフィット） → E（証拠）→ C（コンバージョン）→ O（オファー）→ N → A

## LP目的別パターン

### パターン1: 体験セッション獲得型
- 目標: 無料体験・相談の申込み
- CTA: 「無料で体験する」「初回セッションを予約する」
- 構成のポイント: 体験で得られる具体的な価値を明示。「無料だから損はない」の安心感
- FAQ重点: 「何を話すの？」「強引なセールスはある？」「準備は必要？」

### パターン2: セミナー・講座集客型
- 目標: 特定イベントへの参加申込み
- CTA: 「無料セミナーに申し込む」「席を確保する」
- 構成のポイント: 当日のアジェンダ・得られる知識・登壇者情報を具体的に
- FAQ重点: 「オンライン対応？」「録画視聴は？」「参加後に売込みは？」

### パターン3: 継続契約直接獲得型
- 目標: 有料プログラムへの直接申込み
- CTA: 「プログラムに申し込む」「今すぐ始める」
- 構成のポイント: 実績・事例・変容ストーリーを厚く。料金に対する納得感の醸成が最重要
- FAQ重点: 「成果の保証は？」「途中でやめられる？」「どんな人に向いている？」
  ※「成果保証」は景表法上使用禁止。「多くの方に〇〇という変化が」等で表現する
