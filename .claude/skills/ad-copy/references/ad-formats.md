# 広告フォーマット仕様（2026年6月時点）

## Meta 広告（Facebook / Instagram）

| パーツ | 推奨文字数 | 上限 | 備考 |
|---|---|---|---|
| プライマリテキスト（本文） | 125字 | 制限なし | 125字超は「もっと見る」で折り畳み |
| ヘッドライン | 27字 | 40字 | フィードによっては非表示 |
| 説明文 | 30字 | 30字 | |
| CTAボタン | 選択式 | - | 「詳しくはこちら」「登録する」「今すぐ予約」等 |

**Instagram Stories / Reels:**
- テキストオーバーレイ: 画面の20%以内が推奨
- 縦型（9:16）専用コピーを別途用意すると効果的

---

## Google 検索広告（レスポンシブ検索広告 RSA）

| パーツ | 上限文字数 | 数 | 備考 |
|---|---|---|---|
| 広告見出し | 30字 | 最大15本（3本表示） | どの3本の組み合わせでも意味が通るように |
| 説明文 | 90字 | 最大4本（2本表示） | |
| 最終URL | - | 1 | |
| 表示URL | 15字 × 2 | - | パス1・パス2 |

**ポイント:** 見出しに数字・ベネフィット・キーワードを散らして
Googleの自動組み合わせで最高パフォーマンスが出るようにする。

## X（旧Twitter）広告

- 2026年6月〜: 広告クリエイティブのハッシュタグ使用は効果減少傾向
- 2026年7月〜: URLリンク含む投稿の有機リーチ激減予定
- **広告出稿自体は引き続き可能**（有機投稿の規制とは別）
- テキスト: 280字（半角換算）

| 媒体 | 最低計測期間 | 判断基準 |
