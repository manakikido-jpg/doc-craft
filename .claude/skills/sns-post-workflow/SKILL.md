# 可能性ラボ SNS投稿制作ワークフロー

## 概要

可能性ラボ（キャリアコーチング事業）のInstagramカルーセル投稿を、
タスク一覧の制作フローに沿って1テーマぶん仕上げる。
ゴールは常に「無料市場価値診断への誘導」（面談の直接押しはしない＝診断ファースト）。

## 前提条件

- [ ] テーマが決まっている（未指定なら `assets/post-template.md` の12テーマ一覧から提案）
- [ ] Googleドライブの「可能性ラボ_タスク一覧」「SNSリサーチレポート」にアクセスできる
      （できない場合はその旨を伝えた上で一般知識で代替）

## 手順

### Step 1: リサーチ

テーマに関する統計・よくある悩み・検索ワードを集め、出典つきでメモにする。
進め方と情報源の評価は `info-research` スキルに従う。
ドライブの SNSリサーチレポート・参考アカウント調査があれば優先して使う。

### Step 2: 構成案（A/B 両方作る）

- 共感系A: 共感・あるある → 原因/ヒント → 診断誘導
- ノウハウ系B: ステップ解説 → 具体例 → 診断誘導

スライド枚数と各ページ見出しまで決める。型は `assets/post-template.md`。

### Step 3: ライティング + キャプション

各スライドのテキストと、キャプション本文（A/B各1本）+ ハッシュタグを書く。
キャプションの型: 要約フック → 自己紹介（国家資格キャリアコンサルタント）→
本文 → CTA（無料市場価値診断・完全無料・勧誘なし）→ ハッシュタグ。

### Step 4: 公開前チェック（必須・省略禁止）

`references/compliance.md` の基準で全文を監査し、指摘と修正版を提示する。
DocCraftアプリ上で作業している場合は「公開前チェック」スキル
（`src/lib/content-audit.ts` と同じルール）に文面を貼って確認できる。

### Step 5: 納品

成果物（構成案・本文・キャプション・チェック結果）をまとめ、
依頼者の指示があればドキュメント化（DocCraft / Googleドライブ）する。

## Gotchas（必読）

- ⚠️ CTAは「無料市場価値診断」1本に絞る。面談は添え書き1行まで（二段構えCTA）
- ⚠️ 年収・内定は断定禁止。「目安」「可能性」「目指せる」の表現にする（景表法）
- ⚠️ 「完全無料・勧誘なし」をCTA付近に必ず明記する（ブランド価値「正直に伴走」）
- ⚠️ 実績・事例は事実がある場合のみ。確認できないものは控えめな表現に落とす
- ⚠️ ターゲットは20〜30代・転職で年収アップを狙う層だが、性別は文面で限定しない
