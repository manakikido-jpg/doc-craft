# 表現コンプライアンス基準

`src/lib/content-audit.ts` の監査ルールと同一基準。文面公開前に全項目を確認する。

## 高リスク（公開前に必ず修正）

| 検出対象 | 例 | 言い換え |
|---|---|---|
| 断定・保証 | 必ず / 絶対 / 100% / 確実に / 間違いなく / 保証 | 「目安」「〜の可能性があります」 |
| 成果の断定 | 年収が上がる / 内定できます / 転職が決まる | 「年収アップを目指せる」「選択肢が広がる」 |
| 最上級・No.1 | No.1 / 日本一 / 業界最高・最大・初 / 最安 | 根拠（調査元・期間）併記、なければ削除 |

## 中リスク（要注意）

| 検出対象 | 例 | 対応 |
|---|---|---|
| 安易な訴求 | 誰でも簡単に / 楽して / スキマ時間だけで | 個人差の明記、対象・条件の具体化 |
| 煽り・緊急性 | 今だけ / 期間限定 / 早い者勝ち / 残りわずか | 事実の場合のみ + 根拠（期限・枠数）明記 |
| CTA分散 | 導線キーワード3種類以上 | 主CTA1つ + 副CTAは1行 |
| LINE文字数 | 全角500文字超 | 500字以内 or 最大5通に分割 |

## 低リスク（推奨）

- 「無料」のみ → 「完全無料」と明記（条件付き無料との誤認防止）
- 「勧誘なし」への言及がない → CTA付近に「勧誘は一切しません」を追加
- 60文字を超える行 → 改行と記号で短く区切る（スマホ可読性）

## ブランド原則（可能性ラボ）

- バリューは「正直に伴走」。盛らない・約束しないことが信頼＝CVにつながる
- 実績訴求（未経験から年収アップ等）は事実・実例が確認できる場合のみ
- 導線は 診断ファースト: SNS/あいさつ → 無料市場価値診断 → ステップ配信 → 面談（Day 5〜7）
