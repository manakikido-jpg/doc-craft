# 提案書・事業計画書ワークフロー

## 概要

「提案書を作る」ではなく「相手が Yes と言いやすい文書を作る」ことが目的。
相手の課題→解決策→ROI（効果）→実績→行動促進の流れで構成する。

---

## Step 1: ヒアリング

| 確認項目 | 例 |
|---|---|
| 提案の種類 | 業務委託提案 / 事業計画書 / パートナー提案 / 投資家向け |
| 相手（誰に渡す） | 中小企業の代表者 / 採用担当者 / 投資家 |
| 提案したいサービス | SNS運用代行 / LP制作 / キャリア支援プログラム |
| 相手の課題（推定） | SNS集客ができていない / 採用広報が弱い など |
| 自分の強み・実績 | DocCraft開発 / 〇件のSNS運用 / 国家資格 など |
| 金額感・期間 | 月〇万円 × 〇ヶ月 |
| 納品形式 | PDF / スライド / Word |

---

## Step 2: 構成設計

### 業務提案書（副業・フリーランス向け）

1. **表紙** — サービス名・提案者名・日付
2. **相手の課題の整理** — 現状を言語化して「分かってもらえている」感を作る
3. **提案の全体像** — 一言でサービスを説明
4. **具体的な提供内容** — 何を・いつまでに・どのように提供するか
5. **期待できる効果** — 成果の方向性（断定は景表法違反。「〇〇を目指します」で表現）
6. **実績・信頼情報** — 過去事例・資格・ポートフォリオ
7. **料金・期間・条件** — 明確に。曖昧さは不信感を生む
8. **次のステップ** — 「まずオンラインでご説明する機会をいただけますか」

### 事業計画書

1. **エグゼクティブサマリー** — 全体を1ページで
2. **事業概要** — 何をするか・誰に・どんな価値を
3. **市場分析** — 市場規模・ターゲット・競合（market-strategy スキルと連携）
4. **収益モデル** — 単価・件数・月次売上シミュレーション
5. **マーケティング戦略** — 集客チャネル・LP・SNS・広告
6. **ロードマップ** — 3ヶ月・6ヶ月・1年の目標
7. **リスクと対策**

---

## Step 3: コピーライティング原則（提案書向け）

- **冒頭は相手の課題から始める**（自社紹介から始めない）
- **数字を使う**（「多くの企業」より「導入企業〇社」）
- **ベネフィットをフィーチャーの前に置く**
- **成果は「目指す」で表現**（断定は景表法リスク＋信頼を損なう）
- **最後に「次のアクション」を1つだけ提示する**（複数提示は意思決定を遅らせる）

---

## Step 4: 出力形式

| 形式 | 用途 |
|---|---|
| Markdown | Claude Code内での確認・修正用 |
| DocCraft スライド | プレゼン・PDF提出用 |
| DocCraft ドキュメント | 詳細版・文書として送付する場合 |

DocCraft を使う場合は、add-doc-skill で追加した `biz-proposal` スキルを起動。

---

## Gotchas（必読）

- ⚠️ 「必ずフォロワーが増えます」等の成果保証は景表法違反。「〇〇を目標に運用します」で表現
- ⚠️ 料金は明確に書く。「要相談」のみは印象を下げる（概算レンジでも示す方が良い）
- ⚠️ 提案書は「読まれる」前提で作る。1ページ目で興味を持たせないと最後まで読まれない
- ⚠️ 競合他社を直接批判する表現は使わない
