# 案件ハンティング（クラウドソーシング）

## 概要

LP・Webサイト制作 / SNS運用・コンテンツ制作 / AI・Web開発の案件を対象に、
「探す → 目利きする → 勝てる応募文を書く → 結果から学ぶ」のサイクルを回す。
**案件サイトの自動巡回・スクレイピングは各社規約違反のリスクがあるため行わない。**
検索は人間がブラウザで行い、スキルは検索設計・判断・文章作成を担当する。

## セットアップ

`config.json` が存在しない場合、以下を質問して作成すること:

- 現在のフェーズ（実績作り / 副業安定 / 事業化）と目標月収
- 出せる実績（例: Next.jsアプリ開発、SNS運用設計、LINE導線設計、AI活用）
- 週の稼働可能時間と、受けない条件（NGジャンル・最低単価）

## 手順

### Step 1: 探し方設計

フェーズに応じて媒体と検索条件を設計し、検索キーワード一覧を渡す。

- クラウドワークス / ランサーズ（受注型）: プロジェクト形式 / 予算下限を設定 /
  クライアントは本人確認済み・発注実績ありで絞る
- ココナラ（出品型）: 探すのではなく出品ページを磨く（→ Step 3 の出品文）
- フェーズ別: 実績作り=小規模案件で評価集め → 副業=相場どおりの単発 →
  事業化=継続・月額契約（SNS運用は継続案件の筆頭）

### Step 2: 目利き・地雷判定

案件文を貼り付けてもらい、以下を判定して「応募推奨 / 条件付き / 見送り」で返す。

1. `references/market-rates.md` で相場比を計算（**手数料を引いた手取り**で判断）
2. `references/red-flags.md` の地雷チェックリストで危険シグナルを列挙
3. 自分の実績との適合度と、勝ち筋（何を一番に推すか）

### Step 3: 応募文・出品文・プロフィール作成

`assets/proposal-template.md` の型で作成する。
冒頭は必ず案件固有の内容（テンプレ使い回しはクライアントに見抜かれる）。
納期・金額・修正回数を明記し、最後に質問を1つ入れて返信率を上げる。

### Step 4: リサーチレポートのPDF納品

リサーチ・目利きの結果を `assets/research-report-template.md` の形式でまとめ、
`scripts/md_to_pdf.py` でPDF化して納品する（必要ならドライブにもアップロード）。

```
pip3 install reportlab   # 初回のみ
python3 .claude/skills/gig-hunt/scripts/md_to_pdf.py report.md report.pdf
```

相場の調査は `info-research` の基準（出典・調査日明記）に従う。

### Step 5: 記録・振り返り（メモリ）

応募した案件・結果を `logs/pipeline.md` に追記する。
次回実行時は前回ログを読み、返信率・受注率から応募文と単価設定を調整する。

## Gotchas（必読）

- ⚠️ 手数料はワーカー負担: クラウドワークス5〜20%（報酬額で変動）、ランサーズ16.5%、
  ココナラ22%。同じ5万円でも手取りは3.9万〜4.2万円まで変わる（2026年6月調査）
- ⚠️ 仮払い（エスクロー）確認前に作業を開始しない。「先に着手して」は地雷
- ⚠️ 「詳細はLINEで」「直接契約に切り替えましょう」は規約違反かつ詐欺シグナル。即見送り
- ⚠️ 「実績作りに最適」を口実にした相場半額以下の買い叩きに乗らない。
  実績作りでも下限は相場の7割を目安にする
- ⚠️ 相場の数字は時間で陳腐化する。`references/market-rates.md` の調査日が
  3ヶ月以上前なら `info-research` で更新してから判断する
- ⚠️ AI生成と分かる応募文は逆効果。具体的な固有名詞・数字・制作物リンクで人間味を出す
