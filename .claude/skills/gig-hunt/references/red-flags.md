# 地雷案件チェックリスト

案件文・クライアント情報を以下で採点する。
**赤(1つでも該当=見送り)/ 黄(2つ以上で見送り推奨・1つなら交渉で解消を試みる)** の2段階。

## 赤シグナル（即見送り）

- [ ] 直接取引への誘導（「LINEで詳細」「外部チャットで」「サイトを通さず契約」）
  → 規約違反 + 詐欺の典型。エスクローが無くなり未払いリスク
- [ ] 仮払い前の着手・納品を要求
- [ ] 無償での本制作・本数の多い「テスト納品」要求（採用判断用の軽微なラフは黄で判断）
- [ ] 報酬が相場の半額以下で交渉余地なし（market-rates.md と照合）
- [ ] 高額報酬 × 作業内容が曖昧 × 個人情報・口座情報を先に要求
- [ ] 商材販売・情報商材・グレー業種の集客代行（ブランド毀損リスク）

## 黄シグナル（2つ以上で見送り推奨）

### 案件文
- [ ] 要件・納期・修正回数・納品形式のいずれかが書かれていない
- [ ] 「詳細は契約後に」「まずは応募を」で中身が判断できない
- [ ] 修正「無制限」や著作権全譲渡 + 実績公開不可なのに単価が普通以下
- [ ] 「簡単な作業です」「初心者歓迎」× 実際の作業範囲が広い

### クライアント
- [ ] 本人確認未済 + 評価なし + 発注実績0 の三拍子
- [ ] プロジェクト完了率が低い（目安: 80%未満）
- [ ] 過去評価コメントに「連絡が取れない」「支払いが遅い」がある
- [ ] 同一案件を長期間・大量に再掲載している（人が定着しない案件）

### 条件
- [ ] 実質時給が config.json の下限を下回る（手取り÷想定時間で計算）
- [ ] 「実績作りになるから」を値下げ理由にしてくる（実績は7割が下限）
- [ ] 継続前提を口実に初回を極端に安くさせる（継続保証は契約ではない）

## ココナラ（出品型）特有

- [ ] 購入前メッセージでサービス範囲外の作業を約束させようとする
- [ ] 見積り相談で「他はもっと安い」と値下げ圧力（相場表を根拠に断る）
- [ ] おひねり・追加オプションで精算する前提の曖昧な依頼は、開始前にオプション化する

## 判定テンプレ（目利き結果の返し方）

```
判定: 応募推奨 / 条件付き（交渉点: ◯◯） / 見送り
手取り試算: 提示◯円 × (1−手数料◯%) = ◯円 ÷ 想定◯h = 時給◯円
相場比: [market-rates.md のどのラインと比べたか]
シグナル: 赤◯件・黄◯件（該当項目を列挙）
勝ち筋: [応募する場合、何を一番に推すか]
```
