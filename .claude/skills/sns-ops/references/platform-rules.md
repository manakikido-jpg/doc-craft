# 媒体別ルール・勝ち型・API料金

出典: 可能性ラボ「SNSリサーチレポート 2026-W23-W24」「SNS_API料金リサーチ 2026 v3」。
仕様・料金は変わるため、重要な判断の前に `info-research` で最新を確認する。

## 全媒体共通の原則（2026年上期）

- 「本音・リアル・等身大」が磨き込まれたコンテンツに勝つ。トーンは「正直に伴走」で統一
- 6月下旬〜7月＝夏季ボーナス退職ピーク。「ボーナスもらったら次のステップを。でも焦らないで」フックが最有効
- 退職理由の本音は「人間関係・経済（物価×賃金）」、30代の後悔1位は「情報・比較不足」
  → 無料コーチング（棚卸し・比較支援）の価値訴求と直結

## Instagram

- **勝ち型**: 保存促進型チェックリスト（「転職前に絶対確認したい○つ」）、Q&A形式リール（リプレイ率）、等身大体験談
- **アルゴリズム**: リール優遇強化。シェア率・リプレイ率重視に移行
- **ハッシュタグ**: 上限5個。ビッグ1+ミドル3+スモール1（例: #転職 #中途採用 #キャリアアップ #転職活動 #転職相談）
- **API**: Graph API無料。200req/h、ハッシュタグ検索は週30回、投稿公開は24hで25件まで。
  App Review 2〜4週間（差し戻し多発・スクリーンキャスト品質が重要）

## X（旧Twitter）

- **勝ち型**: 「数字＋本音告白」（例:「本当の退職理由、1位は人間関係でした」）、逆張り常識破り
- **広告仕様**: 2026年6月〜テキストにハッシュタグ禁止、7月〜URL禁止。コピーはビジュアル内に入れる
- **API**: 従量課金。読取$0.005/回、テキスト投稿$0.015/回、**URL付き投稿$0.20/回（高額・手動推奨）**

## TikTok

- **勝ち型**: 機械音声テロップ×ランキング型（「転職でよくある失敗○選」）、Vlog体験談型。冒頭3秒が勝負
- **時期**: キャリア系タグは1〜4月・6〜12月に視聴が伸びる。この期間に集中
- **API**: Research APIは学術限定で競合分析不可。自社分析はBusiness Insights、トレンドはCreator Search Insights

## YouTube

- **勝ち型**: 「○○した末路」ショート（好奇心×結末）、30代のリアルVlog（共感コメント多数）、
  「実績がなくても」系の不安否定・逆張りタイトル
- **API**: Data API無料（10,000unit/日）。検索は100unit/回と高コスト→結果をキャッシュする

## LINE

- **役割**: SNSからの受け皿（診断ファースト導線の本体）。設計は `linemsg` 系資料・DocCraftスキル参照
- **API**: 読取無料。配信はプラン制（無料200通/月、ライト5,000円/5,000通、スタンダード15,000円/30,000通）

## 自動化コストの目安（2026年5月調査・$1=150円）

- 小規模運用合計: 約4,000円/月（X 約970円 + Claude API分析 約3,000円、他は無料枠）
- 中規模運用合計: 約25,000円/月
- AI分析はHaikuバッチ（50%OFF）+プロンプトキャッシュで削減。大量分類=Haiku、レポート生成=Sonnet
