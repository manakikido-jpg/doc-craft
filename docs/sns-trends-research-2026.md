## 0. 全体サマリー（4プラットフォーム共通の大きな流れ）

2026年のSNSを貫く5つのメガトレンド：

1. **「本物さ（オーセンティシティ）」への回帰** … 作り込んだキラキラ投稿より、生っぽい・等身大・失敗談などのリアルが伸びる。日本でも「現実への回帰／リアリティ」が共通テーマ。
2. **アルゴリズムが「フォロワー数」より「コンテンツの質・反応」で配信** … フォロワー0でもバズる時代。各社とも**保存・シェア・DM送信・視聴維持（watch time）**を重視。
3. **ソーシャル検索（ソーシャルSEO）** … Z世代を中心にTikTok/Instagramを検索エンジンとして使う。キャプション・字幕・alt textのキーワード最適化が重要に。ただし「Googleを捨てる」は誇張で、実態は**複数プラットフォーム併用**。
4. **AI生成コンテンツの氾濫と「AIスロップ」への反発、そして表示義務化** … EU AI法（2026年8月）やニューヨーク州法（2026年6月）でAI生成表示が法的義務に。質の低いAI量産は嫌われ、収益化剥奪の標的にもなる。
5. **ショート動画の支配は続くが「やや長め」へ、長尺も復権** … 各社が最大尺を延長。スクロール疲れの反動で、信頼を生む長尺・ポッドキャストも伸びる。

**共通の実践原則:** 最初の1〜3秒のフック / 視聴維持率（完視聴）/ 保存・シェア・DM送信を促す設計 / プラットフォーム横断は「丸ごと転載」ではなく各SNS向けに再編集（透かし除去・キャプション書き換え）。

## 1. X（Twitter）

### アルゴリズム — Grokベースの「AIファースト」エンジンへ刷新
- For You / Following の両フィードが、xAIのGrok由来のトランスフォーマーモデルでランク付けされるように刷新。Musk曰く2025年11月までに「完全AI駆動」化。**2025年11月30日**に Following の純時系列タイムラインの役割を廃止。
- **2026年1月20日**、新フィードのコードを GitHub（`github.com/xai-org/x-algorithm`）でオープンソース化。**Thunder（フォロー内）**と**Phoenix（フォロー外のML発見）**の2系統の候補を、Grok-1派生モデルで評価。15以上のアクション（いいね・返信・リポスト＋ブロック/ミュート/通報などのネガ信号）を予測。動画は P(動画視聴) と尺を別途評価。
- **Grokが本文・動画を直接読むため、ハッシュタグは発見にほぼ無意味**に（意味的に分類される）。

### リーチを生む反応シグナル（概算の重み付け、2023年公開版由来で方向性のみ確実）
| シグナル | 概算の重み |
|---|---|
| いいね | 1x（基準） |
| ブックマーク | 約10x |
| リンククリック | 約11x |
| プロフィールクリック | 約12x |
| 返信 | 約13.5x |
| リポスト | 約20x |
| **投稿者が返信に再返信** | **約75x** |

- **「会話（返信＋投稿者の再返信）＝いいね約150倍」**。アルゴリズムはスレッド状の往復を強く優遇。ネガ信号（ブロック・ミュート・通報・興味なし）は直接リーチを抑制。滞在時間も重要。

### 伸びるフォーマット
- **縦型ショート動画**が最大の押し。フォロー外の動画を流すスワイプ式の縦型フィードが発見チャネルに。
- **スレッド**（4〜7投稿が最適とされる）、**長文Articles**（Premium機能、最大25,000字、賞金施策で奨励との情報）。
- **コミュニティ内での認知**とトレンドへの即応が候補選定に効く。

### 収益化（2025〜2026の変更）
- エンゲージメント基準から**「インプレッションの質」基準**へ。**2026年1月時点**で、**認証/Premiumユーザーによるホームタイムラインのインプレッション**で算定。**返信のインプレは対象外**（インプレ稼ぎ対策）。オリジナル投稿者を特定して支払う。
- **条件:** X Premium/Premium+（Basic不可）、**500フォロワー以上**、3か月で**500万インプレ以上**。
- ※「収益プール2倍／累計$45M支払い／Article賞金$1M」等は単一の取得不可ソース、要検証。

### 投稿の目安（ツールブログ発、ルールオブサム）
- 頻度: ブランド3〜5投稿/日、個人1〜3投稿/日。日10超で1投稿あたり約14%低下との指摘。
- 時間: 火・水・木が強い。ピークは火9時、9〜15時が広いスイートスポット。
- 長さ: 単発投稿は約71〜100字が反応の目安。

### 日本特有
- 2024年12月の大刷新（評価パラメータ約10倍）。**「バズ狙い」から「信頼・質・ニッチコミュニティ・返信主体の会話・継続」へ**という日本の代理店の共通見解。

## 2. YouTube

### 伸びるフォーマット
- **動画ポッドキャストが最大の成長ストーリー（確度高め）** … 月間視聴者10億人、米国でのTV経由視聴は2025年10月に700M時間超（前年の約2倍）。**米国週次リスナーの33〜37%にとってYouTubeが最大のポッドキャスト基盤**（Spotify超え）。
- **長尺の再評価**（ショート金鉱熱の反動）。長尺（15分+）が総エンゲージメントの約半分との指摘。
- **顔出しなし/AI自動化チャンネルの急増**（※「2026年に新規収益化の38%」等の数字はAIツール業者発で誇張の可能性、定性的トレンドは本物）。
- ライブのクリップ/ショート自動転用、ショートは高ボリュームだが収益は弱い。

### アルゴリズム・ポリシー変更（最も検証可能なセクション）
- **ショートの「視聴」定義変更（2025年3月31日）** … 再生/リプレイ開始の瞬間に1視聴（最低秒数なし）。ただし**収益化・YPP資格は従来基準の「エンゲージド視聴」のまま**。つまり大きな視聴数≠収益増。
- **「非本物（inauthentic）コンテンツ」ポリシー（2025年7月15日）** … テンプレ量産・ほぼ同一ナレーション等を収益化対象外に。**AIは禁止ではない**。リアクション/解説/編集/まとめは対象外。
- **2026の方向性:** 「最も長く見せる」→**「最も満足させる」**へ。フォーマット認識型推薦（ショートをよく見る人にショートを配信）。ショートが検索/ホームにも露出→タイトル・説明のキーワード最適化が必要に。

### 最適な尺・サムネ・タイトル・頻度
- **長尺は7〜15分**がスイートスポット。**ミッドロール広告は8分以上が条件**。**尺より視聴維持**。
- **サムネ文字は0〜3語**が最高CTR。1280×720・16:9・2MB未満・高コントラスト・表情。ネイティブのTest & Compareで A/B。
- **タイトルは40〜65字**、最重要部を先頭約40字に。サムネとタイトルは重複させず役割分担。
- 冒頭**3秒**のフックが勝負。

### 収益化
- **ショート経路:** 1,000登録＋**90日で1,000万有効ショート視聴**。**長尺経路:** 1,000登録＋**12か月で4,000有効公開視聴時間**。
- **ショートRPMは低い** … 1,000視聴あたり約$0.01〜0.07（強いニッチで〜$0.10）。地域差大。
- ミッドロールは自然な切れ目に配置（自動＋手動併用で約5%増）。高CPMニッチ: 金融($15〜45)、テック、AI。

### 日本特有
- 人気ショートジャンルは**VLOG・情報発信・あるあるネタ**。2026は「実益と対話」=検索性ある資産型コンテンツへ。**VTuber**と**切り抜き**文化が引き続き強力。

## 3. TikTok

### 米国の禁止/分割問題のステータス（2026年6月時点・事実）
- 騒動は**収束**。米国で通常運用中（アカウント・フォロワー・履歴は維持）。
- **2026年1月22〜23日に成立。** 新会社 **TikTok USDS Joint Venture LLC**。**米国/グローバル投資家が約80.1%、ByteDanceは19.9%**保有。**Oracle・Silver Lake・MGXが各約15%**。**評価額 約140億ドル**。
- **アルゴリズムはByteDanceが所有権を保持しライセンス供与**。推薦エンジンと米国ユーザーデータはOracleの米国内クラウドに格納、米国データで再学習。CEOは Adam Presser、取締役にShou Chew。
- ※「安全保障上の懸念は解消」かどうかは批判もあり論争中。

### いま伸びるフォーマット・トレンド（陳腐化注意のスナップショット）
- **写真カルーセル（フォトモード、最大35枚）がアルゴリズムで強力にブースト** … 約70万投稿の分析で動画比+81%エンゲージ・+82%いいねとの解析。
- GRWM、day-in-the-life、生っぽいリアル系が定番。**スタックフレーム/グリッチ編集、7秒リップシンク、演技チャレンジ**が機能。
- 流行楽曲/チャレンジ例（2026年中頃）: CORTIS「wiggle-ears」チャレンジ（K-pop横断）、各種グリッチ編集、リップシンク系。
- AIリップシンク・AIナレ・AIカルーセルも氾濫。**フックが持てば**アルゴリズムは依然評価。

### アルゴリズム・尺・時間（2026）
- **15秒時代は終了。30〜60秒が最多の高パフォーマー、60〜180秒が優先配信される傾向**（視聴維持で有利）。尺はもう penalty ではない。
- 中核シグナルは**完視聴率**と**最初の1時間のエンゲージ速度**（特にシェア・保存）。
- 頻度は**週3〜4本の質重視**。投稿時間は夕方が強い（木曜午前・土曜昼など）。

### TikTok Shop / 収益化
- **TikTok Shop 米国GMV 2025年約158億ドル（前年比+108%）**、米国ソーシャルコマースの約18.2%。2026年は約234億ドル見込み。
- **Creator Rewards Program**（1分超動画対象）: 概ね1,000有効視聴あたり**$0.50〜1.50**。資格は18歳以上・**1万フォロワー**・30日で**10万本物視聴**等。
- 実収益の主力は**Shopアフィリエイト・LIVEギフト・ブランド案件**の多角化。

### 日本特有
- **「現実への回帰／リアリティ」**が支配的テーマ。トレンドは数日で全国波及。**検索・購買インフラ**として利用。流行音源は「mosi mosi?」等。

## 4. Instagram

### アルゴリズム — フォロワー/いいねから「DM送信・視聴時間」へ
- Mosseriの示す上位シグナルは**視聴時間・sends-per-reach（DMシェア）・likes-per-reach**。**DM転送（sends）がいいね/コメントより重く評価**。
- **フォロワー数の重みは低下**（「フォロワー0でもバズる」の根拠）。**オリジナル優遇・転載は降格**（AIで転載検出）。Feed/Reels/Stories/Exploreで別アルゴリズム。
- **ハッシュタグはリーチ手段ではない**（Mosseri明言）。2026は文脈/発見（検索・Explore）用途。関連数個で十分。

### 伸びるフォーマット
- **Reels＝発見エンジン**（最大3分がフォロー外に推薦され得る）。
- **カルーセル＝保存/エンゲージの王者**（単一画像比 約2.14倍との集計）。**上限20枚に拡張＋投稿後の並べ替え**が2026の目玉。日本は8〜10枚推奨、4〜7枚は「死の谷」。
- **写真の復権**は主に**カルーセル内**で。**単一画像はリーチ最低**。
- **Stories＝コミュニティ/維持**（発見ではない、1〜2回/日）。
- **Trial Reels**（フォロー外のみに先行公開してテスト、1,000フォロワー以上）。※通常Reelsより**リーチは少なめ**になりがちで、テスト/リード用途向き。

### 最適な尺・頻度（多くは代理店データ）
- **7〜15秒＝バズ/発見**（ループ再生で有利）、**60〜90秒＝教育**（総視聴時間で有利）。
- 日本では**5秒未満のループ音源**で中毒的リプレイが2026トレンド。音源は**ピーク前の上り調子**を使う。
- 頻度は質重視。集計的な最適は週Reels2〜4本＋カルーセル2〜3本＋静止画1〜2本。日本は**リール7：フィード3**。

### 収益化（ボーナス終了後）
- ⚠️ **「Reels Play Bonusが2025年8月31日終了」は未確認。** 事実関係: 元のReels Play Bonusは**2023年に終了**、別の creator ad プログラムが2025年に終了。
- 現行: **ギフト（Stars）・サブスク（$0.99〜99.99/月）・ブランド案件/アフィリエイト**が主。期間限定の選抜ボーナス（Breakthrough Bonus 最大$5,000、Referral Bonus 最大$20,000）も。

### 日本特有
- **発見タブ**重視。鍵は**保存率・ホーム率・滞在時間**の3指標。DM送信を重視・オリジナル優遇は英語圏と同じ。

## 5. 横断的な戦略と収益化マクロトレンド（2026）

### コンテンツの大きな潮流
- **AIは「標準装備」化、同時に「AIスロップ」反発** … Mosseri「作れるか？→あなたにしか作れないものか？」。怒りの対象は*無加工の*量産物。
- **オーセンティシティ／深さ＞規模** … 「バーチャル追求からコミュニティ構築へ」。Sproutの2026フレーミングは「つながりこそ通貨」。
- **コミュニティ主導の成長・ブランドワールド**（キャラ・世界観・lore）。
- **ソーシャル検索** … 「商品発見の60%超」がTikTok/Instagram/YouTubeとの調査も。ただし「Google代替」は誇張、実態は併用。
- **ショート支配＋やや長め＋長尺復権。UGC・マイクロインフルエンサー＞作り込み。**

### クリエイターエコノミー
- 市場規模は定義で大きく割れる（約2,000億ドル〜1.2兆ドル）。インフルエンサーマーケは2026年約340億ドル。

### AI生成コンテンツの規制（最も確度が高い）
- **EU AI法 第50条**の透明性義務が**2026年8月2日**施行。AI生成/加工の画像・音声・動画は表示義務。
- **ニューヨーク州法**（2025年12月11日署名、要件は**2026年6月**開始）= AI「合成パフォーマー」の広告表示を義務化。
- **FTC**: 表示しても本質的に誤認させるAIは規制対象。
- 各社: Meta（C2PA/IPTCで画像自動検出、AI動画/音声・バーチャルインフルエンサーは手動表示）、TikTok（自社AIツールは自動表示）、YouTube（リアルな合成は表示要）。
- **表示を「信頼シグナル」に転換**する動きも。

### 推奨2026戦略
- **主力1プラットフォーム＋1フォーマットに集中→意図的に再利用**（丸転載しない、透かし除去、ネイティブ再編集）。
- プラットフォームの役割分担: YouTube Shorts＝検索・常緑、TikTok＝オーガニックリーチ・文化的即応、Instagram Reels＝既存層統合・Meta広告基盤。

- 日本: AI駆動のコミュニティ構築、SNSの**営業資産化**、EC×SNS統合が3本柱。

## 7. 結論：2026年に押さえるべき要点

1. **フォロワー数より「反応の質」。** 各社とも保存・シェア・DM送信・視聴維持・会話（返信）を評価。フォロワー0でもバズれる。
2. **最初の3秒のフックと完視聴率がすべての基礎。**
3. **本物さ＞作り込み。** リアル・等身大・「あなたにしか作れないもの」。AIスロップの量産は逆効果かつ収益化リスク。
4. **尺は伸長傾向。** TikTok 30〜180秒、IG Reels 7〜15秒(バズ)/60〜90秒(教育)、YouTube長尺7〜15分。用途で使い分け。
5. **ソーシャル検索最適化**（キャプション・字幕・alt textのキーワード）。
