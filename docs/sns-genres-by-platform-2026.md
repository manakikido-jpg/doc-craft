## 0. 4プラットフォーム共通の地殻変動

- **「本物さ（リアル）」への回帰** … 作り込みより生っぽさ。TikTokは公式トレンド報告で「Reali-TEA（リアリティ）」、日本でも「現実への回帰」「引き算の美学」。
- **AI生成への反発と二極化** … 「AIスロップ」嫌悪が広がり、見世物的AIより**実用的AI**へ。TikTok公式テーマは「Irreplaceable Instinct（人間の本能こそAIへの解毒剤）」。
- **保存・シェア・完視聴・返信が通貨** … フォロワー数より「反応の質」。
- **ニッチ特化（小さな専門性）＋コミュニティ帰属** … 「○○×属性」の掛け合わせで発見・常連化を狙う。
- **ソーシャルコマースの台頭** … TikTok Shopを筆頭に、アプリ内で発見→購入が完結。

## 1. X（Twitter）の流行ジャンル

Xの2026年の核心は**「返信欄をコンテンツ化する」**こと。アルゴリズムが返信・滞在時間を重視するため、リプライを生む仕掛けが勝つ。

### ① レイジベイト / 炎上 / ホットテイク
わざと怒らせる・物議を醸す投稿で返信と引用を稼ぐ。2024年以降のアルゴリズムが返信・滞在を優遇するため機械的に有利。ただし飽きも来ており、Xは2026年3月に政治/扇動コンテンツを減らすフィルタを導入。日本では「拡散から信頼へ」の揺り戻し。

### ② AI生成動画 / AIスロップ
Grok Imagine（SuperGrok/Premium+、月$30〜35）で6秒の音声付きクリップが量産可能に。政治風刺（レゴ風）、企業風刺（不気味に笑うCEO=「Grimacing CEO」ミーム）など。2026年に**真に新しいジャンル**だが、定着性は不透明。

### ③ 縦型ショート動画（ネイティブ＋切り抜き）
9:16動画がX最大のフォーマット級トレンド。before/after、チャレンジ、配信/ポッドの切り抜き。冒頭3秒のフックが鍵。美容ブランドが「メイクbefore/after」で平均視聴維持85%の例。「ニヒリスティック・ペンギン」がTikTok→Xへ波及しBMW/Lidl等が便乗。

### ④ ミーム / シットポスト / 不条理ユーモア
高コンセプトな不条理・シュール笑いが2026年のXコメディを支配。引用での「乗っかり（remix）」で拡散。例:「Baked Potato With Ski Goggles」「Skyrim cheese wheel」「KitKat Heist」。

### ⑤ 長文エッセイ / スレッド（ビジネス・自己啓発・知識）
Premiumの長文・収益分配が後押し。フック→番号付き価値→CTA。「汎用な生産性」より「ブートストラップSaaS創業者」等のニッチ特化が伸びる。

### ⑥ Build in Public / 個人開発 / お金
創業者がMRR・売上を公開（#buildinpublic）。AIラッパー製品が最速成長サブセット。例: ソロ開発で年$602Kのような具体数字がブックマークを生む。⚠️ ただし**生存バイアス**（中央値の個人開発者はそんなに稼いでいない）。

### ⑦ テック / AI / 暗号資産の論評
XはAI業界の事実上の本拠地（OpenAI/Anthropic/Google/xAI/Cursorが活発）。バイラルな「コーディングデモ」、「モデルX vs Y」比較、ローンチ反応スレ。

### ⑧ ファンダム / 推し活 / アニメ / K-pop
Stan Twitter。ファンカム、ファンエディット、考察スレ、投票ドライブ。例:『KPop Demon Hunters』がX/Discordを「考察ラボ」化。組織化されたファンが拡散の増幅装置に。

### ⑨ スポーツのライブ実況
試合中の秒単位のファン反応。2026年W杯（米開催）が巨大ドライバー。例: ドイツ人サポーター「Freddy」がバイラル化。※FIFA公式クリップはTikTok提携のため、Xのライブ実況首位は競争中。

### ⑩ 政治
⑨①と重複。アウトレイジ機構＋選挙サイクル。ただしXはCommunityNotesや政治コンテンツ削減フィルタで**抑制側**に動いており逆風も。

### ⑪ 日本特有（大喜利・漫画・イラスト・考察・素材配布）
- **素材配布×大喜利:** 2025年日本の代表トレンド。ブランドが「遊べる余白」（テンプレ画像）を投稿し、**返信欄が大喜利でコンテンツ化**。マクドナルド日本「大喜利素材に！」など、1投稿で数万リポスト。
- **漫画（実話エッセイ漫画）:** 自主制作漫画が安定バズ。2025年は哲学的テーマ・前向きな生き方系。
- **イラスト:** オリジナル創作で一次創作者がファン拡大。
- **考察:** アニメ・作品の深掘り分析スレ（西洋の「lore lab」に相当）。
- 日本のXは「拡散」より「交流」を評価し、参加型（大喜利・素材配布）が返信エンゲージを量産。

## 2. YouTube の流行ジャンル

### Tier 1 — 最も明確な構造的勝者

**① 動画ポッドキャスト / トーク / インタビュー（最も確度の高いトレンド）**
音声でなく「映像ファースト」のポッドキャスト。YouTubeは月間ポッド視聴者約10億人、米国で最大基盤（約33%、Spotify超え）。2025年10月はTV画面での視聴が700M時間超。例: Joe Rogan、Diary of a CEO、Kill Tony。45〜120分超・週次・複数カメラ。※制作と関係構築のハードルが高く初心者の顔出しなし向きではない。

**② 顔出しなし/YouTube自動化ニッチ（AI支援）**
ナレ＋ストック/AI映像。週3〜5本量産。良ニッチでRPM約$8〜21。ホットなサブニッチ:
- **実話怪談/ミステリー/ホラー語り**（例: Mr. Nightmare 約600万登録）
- **Reddit物語/ナレーション**（r/NoSleep系、需要「飽くなき」）
- **金融解説、AIツール/AIニュース、歴史、モチベ、ドキュメンタリー調**
⚠️ **最も過剰宣伝されるカテゴリ**。飽和が激しく、YouTubeも低品質AI量産（非本物コンテンツ）を規制強化。「不労所得」系は懐疑的に。

**③ AIツール/AIワークフロー/テック解説**
AI製品のレビュー・チュートリアル。SaaS/AIスタートアップが高単価でCPMが平均比30〜40%高との情報。画面録画＋ナレで顔出し不要。

### Tier 2 — 高CPMの「お金」ニッチ（成熟・競争激）

| ニッチ | 報告CPM/RPM（米国・概算） | 備考 |
|---|---|---|
| **パーソナルファイナンス/投資** | CPM約$18〜45 | 何度も#1。「金融はゲームの約10倍」 |
| **保険/法律/税** | CPM約$15〜80+ | プレミアム広告主 |
| **ビジネス/起業** | CPM約$14〜35 | 「○○の始め方」 |
| **不動産/不動産投資** | CPM約$12〜60 | 幅広い |
| **ソフト/SaaS/テックレビュー** | CPM約$10〜25 | 米国視聴者でRPM上昇 |
| **健康/ウェルネス/長寿** | CPM約$6〜15 | 医療/サプリは高め |

- サブニッチ選びが収益を支配（「飲食店の始め方」＞「簡単パスタ」）。

### Tier 3 — 大ボリューム/エンゲージ系（低CPM・高リーチ）

**④ ゲーム/配信/VTuber切り抜き**
リーチ大・CPM低（長尺ゲームRPM約$2〜8）。**切り抜き**は日本＋英語圏で成長（CPM約¥200〜400、上級で月¥120万例）。⚠️ 2026年の収益化審査は「字幕だけでは不十分、独自の付加価値（コメント・演出・構成）」を要求。

**⑤ ASMR/満足感/睡眠系＋サイレントvlog**
無言の睡眠導入、ロールプレイ、フードASMR。「音声オフ視聴」増が追い風。2026年の差別化は**制作品質**。サイレントvlog/スローライフが隣接成長。

**⑥ 教育/解説/ビデオエッセイ**
常緑・検索流入・ブランド案件取りやすい。日本では教育・学習系が最安定（英語・プログラミング・簿記・大学受験）。2026は「冒頭5秒で課題解決」、15〜30秒のマイクロ解説も伸長。

**⑦ リアクション＆論評** … 低コストで根強いが2026の突出データは薄い。
**⑧ Vlog/日常/スローライフ** … スマホ＋編集で初心者向き。サイレント版が成長エッジ。
**⑨ 料理・DIY・テックレビュー・キッズ/ファミリー** … 料理RPM約$3〜10（健康料理が高め）、テックレビュー約$15〜25。キッズはCOPPA制約。

### 日本特有（2026）
- ショート視聴の人気: **ペット・動物32.5%、音楽31.4%、料理29.5%**（女性はペット・料理が突出）。
- **解説系/雑学/知識系**が安定。**AI・テクノロジー解説**は未開拓の好機。
- **あるある系/スカッと系/泣ける話**は高再生になりやすい。
- **ゆっくり解説・朗読系**が顔出しなし定番。**ペット**は安定高再生。

## 3. TikTok の流行ジャンル

### 公式トレンド報告「TikTok Next 2026」の3シグナル
- **Reali-TEA** … 正直・コミュニティ・舞台裏のリアル
- **Curiosity Detours** … 非線形な発見、寄り道・ラビットホール
- **Emotional ROI** … 時間/お金への「見返り」、意味ある物語が購買を駆動
- 隣接テーマ: **#TheGreatLockIn（自己研鑽コミット）**、日本では「現実への回帰」「引き算の美学」。
- ⚠️ 尺の最適は諸説対立（60秒+を推す説と15〜30秒を推す説）。「ニッチ＋完視聴率次第」が実態。

### ① GRWM/美容/モーニングルーティン/日常
カメラに話しかけながら身支度。30〜45秒、ささやき声、手の甲での商品デモ。2026美容は「クリーンガール→ノーメイク風メイク」「ガラス肌」。

### ② 写真カルーセル（フォトモード）
4〜35枚のスワイプ式。**各スワイプがエンゲージ信号＋完視聴率重視**で高リーチ（⚠️「5〜10倍」はツール業者の誇張）。**5〜7枚**が目安、教育リスト系が好調。**2025〜26の明確な構造変化**。

### ③ TikTok Shop/商品レビュー/「TikTokで買った」/ハウル
**#TikTokMadeMeBuyIt（3000万本+）**。家事/キッチンガジェット、美容、ガジェット。購買層は25〜34歳が中心。**日本**ではTikTok Shopが急拡大（初6か月でGMV150億円超、2026年末約1283億円予測）、**35〜54歳女性**＋**昼の生配信コマース**が特徴。

### ④ 料理/レシピ/モッパン/店レビュー（FoodTok、日本では飯テロ）
2026: 「セイボリーマキシング」（塩系・ピクルス）、バナナブレッドラテ、ヨーグルトティラミス等。⚠️ 最速で陳腐化するカテゴリ。

### ⑤ ダンス/リップシンク/チャレンジ
低参入・リミックス可・音源駆動（ピーク前の音源使用が鍵）。例（すぐ古くなる）: 「Let Me Be」「Shake It」、Espresso/Apple系。

### ⑥ コメディ/スキット/POV/あるある
**ユーモアは#1のバイラル駆動**（シェア＋リピート）。金融コメディ・ペットコメディ等と融合。

### ⑦ サブコミュニティ（-Tok）
**#BookTok（世界8000万投稿超）**が書籍売上を動かし、文学/哲学/金融書へ細分化。**CleanTok**（エコ掃除）、**PlantTok**（観葉植物→6桁ビジネス）、**GymTok/FitTok**、**#MomTok/#DadTok/#WitchTok**。

### ⑧ 教育「エデュテインメント」/ハウツー/金融
専門＋物語/笑い。**パーソナルファイナンス**が最有望の一つ。例: Mrs. Dow Jones（ポップ＋コメディ金融）。実用AIハウツー、サステナ、メンタルヘルスも隣接。

### ⑨ ストーリータイム/「身支度しながら話す」
平凡な作業に物語を重ねて視聴維持。2026年は無加工の個人/歴史/キュレーション物語が最高視聴時間。マイクロドキュメンタリー化。

### ⑩ ペット/動物（PetTok）
普遍的にシェアされる。#PetTok、#dogsoftiktok。（出典は弱め＝TikTok発見ページ中心）

### ⑪ AIコンテンツ/「Brainrot」
**Italian Brainrot**等。公式テーマが「人間の本能＝AIへの解毒剤」を打ち出した通り、見世物的AIの新鮮味は薄れ**実用AI**へ。

### 日本特有
- マクロ: 「現実への回帰」「引き算の美学」（リミックス/二次創作を誘発）。「型にハメる」テンプレ成長。
- 2026年1月: **トラベル**急伸（アプリ内予約開始）、**アフターワーク（夜）ルーティン**vlog（西洋の朝ルーティンの日本版）。
- 定番: **あるある・大喜利・飯テロ・切り抜き**。
- コマース: TikTok Shop＋**昼の生配信コマース**が活況、TikTok GOが実店舗送客。

## 4. Instagram の流行ジャンル

### 横断コンテキスト
- アルゴリズムは「関係性＋保存/シェア」を評価。フォロワー数より**ニッチ権威**。
- フォーマット経済: **Reels＝発見**（約36%多いリーチ）、**カルーセル＝エンゲージ/保存**（約10%台のエンゲージ率）。最適ミックスはReels6〜7：カルーセル2〜3。
- 美学は**作り込み→等身大**へ。日本は**保存（保存率）**が最重要KPI。

### ① ファッション/OOTD/美容/GRWM
最大級ニッチ（美容Reels約430万本との集計、K-beauty「ガラス肌」が牽引）。主にReels（変身・GRWM）、OOTDはカルーセル/フォトダンプも。日本では美容＝日々の再利用価値で**保存されやすい**。

### ② フォトダンプ/エモいライフスタイル/キャンディッド
5〜10枚の混在カルーセル。過剰な作り込みへの反動。統一トーンで「自然なのにエモい」を演出。

### ③ 教育カルーセル（ビジネス/金融/自己啓発/Tips）
**教育は娯楽よりほぼ常に高コンバート**、**保存の最強ドライバー**。**パーソナルファイナンス**が最も熱い/稼げるニッチの一つ。教育は8〜12枚、深いガイドは12〜20枚。

### ④ 料理/レシピ/カフェ
最大級でバイラル化しやすい。**ステップ式カルーセルが単一料理写真を上回る**。日本ではグルメ/スイーツが**保存トップ級**（「後で見返したい」）。

### ⑤ 旅行/「行くべき場所」/ローカルガイド
2026は**超ローカル探索**（自分の街の穴場、日帰り）。実際に行けて行動可能なのが強み。Reels（映画的フック）＋保存リスト型カルーセル。

### ⑥ フィットネス/ウェルネス/「that girl」/ルーティン
フィットネスReels約170万本。**自宅ワークアウト**（最小器具）が好調。「クリーンガール/that girl」ライフスタイル。日本では「簡単に始められそう」が保存されやすい（例: 竹脇まりな）。

### ⑦ 住まい/インテリア/DIY/整理収納
**before/after変身**が最強構造。日本は概念特化（「インテリア×OL×ナチュラル」）。※マキシマリズムがミニマリズムへの対抗で台頭との予測も。

### ⑧ あるある/カップル/家族/ペット
**コメディ/あるあるはシェア率最高**（DMシェア＝上位信号）。子育て「子どもの珍行動」が作り込み家族より強い。**ペットインフルエンサー**は2026成長領域。

### ⑨ ミーム/エンタメReels
全カテゴリ最高のシェア率。顔出しなしに強い。

### ⑩ マイクロニッチ個人ブランド＆UGC/顔出しなし
2026最大の構造テーマ＝**単一トピックの権威**。ブランドはマイクロインフルエンサー＋UGCへ予算移行。稼げる顔出しなしニッチ: 金融・投資・生産性・健康・マーケ・子育て。保存資産（チェックリスト/テンプレ）優先。

### 日本特有（保存が鍵）
- **グルメ/スイーツ**（後で見返す）、**美容**（日々の再利用）、**ファッション/コーデ**（トレンドだが実用）、**暮らし/インテリア/整理収納**（概念特化＋before/after）、**お役立ち/ライフハック（お金・節約・子育て）カルーセル**、**フィットネス/ダイエット**（始めやすさ）、**ペット/子育て**。
- 戦略は体験型・マイクロインフルエンサー/UGC・「小さな専門性」での発見最適化。

## 5. 横断まとめ：プラットフォーム×ジャンルの早見

| | 最も伸びるジャンルの軸 | 顔出しなし適性 | 収益化の主軸 |
|---|---|---|---|
| **X** | 返信欄をコンテンツ化（大喜利/ホットテイク/AI動画/ミーム/スレッド） | 高（ミーム/スレッド/AI） | インプレ収益＋サブスク（薄い） |
| **YouTube** | 動画ポッド・高CPM解説（金融/AI）・顔出しなし語り | 中〜高（解説/語り/切り抜き） | 広告（高CPMニッチ）＋案件＋会員 |
| **TikTok** | リアル系・写真カルーセル・コマース・-Tokコミュニティ | 中（カルーセル/AI/語り） | TikTok Shop/アフィリ＋ギフト |
| **Instagram** | 教育カルーセル・美容/グルメ/暮らし・フォトダンプ | 高（教育/ミーム/UGC） | ブランド案件＋アフィリ＋ギフト/サブスク |

### 共通の勝ち筋（2026）
1. **冒頭3秒のフック**と**完視聴/保存/シェア/返信**の設計。
2. **ニッチ特化（○○×属性）**で発見・常連化。
3. **リアル＞作り込み**。「あなたにしか作れないもの」。
4. **実用AIは武器、見世物AIスロップは逆効果**（かつ表示義務化へ）。
5. **横断展開は丸転載でなく各SNS最適化**（透かし除去・尺/キャプション調整）。

## 6. 信頼性・注意
