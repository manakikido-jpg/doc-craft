# XやYouTubeで流れてくる「AI動画」の作り方リサーチまとめ

> 調査日: 2026年6月 / 対象: X(Twitter)・YouTube Shorts・TikTok・Instagram Reels でバズっている AI 生成動画
>
> **注意:** 生成AIツールの料金・モデルのバージョン・機能は毎月のように変わります。本書の数値（価格・秒数・解像度など）は調査時点での目安です。実際に使う前に各サービスの公式ページで最新情報を必ず確認してください。各社の公式価格ページは自動取得をブロックしていることが多く、一部の数値は二次情報（レビューサイト等）に基づくため、特に料金は参考値として扱ってください。

## 0. 結論（まず全体像）

いま流れてくる AI 動画は、ざっくり次の3系統に分けられます。

1. **実写級のAI生成クリップ系** … Sora 2 / Veo 3 などで作る「本物みたいな映像」。ASMR、動物、POV歴史もの、AI広告など。バズの主役。
2. **AIアバター/しゃべる系** … HeyGen / Synthesia / Captions などで「人がしゃべる動画」を撮影なしで量産。解説・UGC広告・多言語化向け。
3. **自動編集・スライド系** … Vrew / CapCut / InVideo などで台本から字幕付き動画を自動生成。顔出し不要の解説チャンネル向け。

**重要な前提:** 1本の動画は1つのツールで完結しないのが普通です。**台本(ChatGPT/Claude) → 画像生成 → 動画化 → 音声(ElevenLabs) → BGM(Suno) → 編集・字幕(CapCut)** のように、工程ごとに専門ツールをつなぐ「モジュール型ワークフロー」が主流です。撮影スキルより**プロンプト設計と演出（ディレクション）**が勝負どころになりました。

**OpenAI Sora 2 / Sora 2 Pro**
- テキスト/画像→動画。**映像と音声（セリフ・効果音・環境音）を同時生成**できるのが最大の強み。
- 「Cameos（カメオ）」= 本人の見た目を認証して映像に登場させる機能がバズの中心。
- 2025年9月30日に専用iOSアプリとともにローンチ、5日で100万DL超、米App Storeで約3週間1位。
- 料金: ChatGPT Plus $20/月（720p・約10秒・透かしあり）、ChatGPT Pro $200/月（1080p・約20秒・透かしなし）。API は概ね秒$0.10〜0.50。
- ⚠️ 最大長は15秒か25秒か、ソースにより記述が割れます。

**Google Veo 3 / 3.1（＋Google Flow）**
- テキスト/画像→動画。会話・効果音・環境音などの**ネイティブ音声が非常に優秀**。Gemini アプリ経由で世界中に配信。
- 「Flow」は Veo + Imagen + Gemini を束ねた映像制作フロントエンド。
- 料金: Google AI Pro $19.99/月、Google AI Ultra $249.99/月。Google Labs 経由で無料お試し枠あり。API は Veo 3.1 標準で秒約$0.40。
- 2025年10月に Veo 3.1 公開（音声強化、Standard/Fast/Light の派生）。

**Runway（Gen-4 / Aleph）**
- キャラ・シーンの**一貫性が業界トップクラス**（参照画像ベース）。「Aleph」(2025年7月) は既存映像の編集（再ライティング、物体追加削除、別アングル生成）ができるモデル。
- 弱点: 基本生成にネイティブ音声がなく、ネイティブ解像度は720p。
- 料金: 約$12〜188/月。Gen-4 Turbo は5クレジット/秒。

**Kuaishou Kling（2.6）**
- **安くて非常に高リアル**。物理挙動・モーションが強い。2.6（2025年12月3日）でネイティブ音声に対応。
- 料金: 約$6.99〜64.99/月。API は音声オフ秒$0.07、音声オン秒$0.14。
- 中国系のため、データ・アクセス面を気にする人もいます。

**MiniMax Hailuo / Pika / Luma / Midjourney V1**
- Hailuo: 重力・流体など物理表現がリアルで低コスト。クリップは約10秒まで。
- Pika 2.2: 安価で楽しい「Pikaffects」。リアルさより遊び向き。無料枠あり。
- Luma Ray3: 映画的カメラワークと16bit HDR が強み。**音声生成はなし**。
- Midjourney V1: 画像→動画専用（テキスト単体からは不可）。**美的・スタイル表現は随一**。5秒クリップを最大約21秒まで延長可。

### 各ツールの要点
- **HeyGen:** 約15秒〜数分の自撮りから「デジタルツイン（自分の分身）」を作成。1100以上のストックアバター、170以上の言語、強力なリップシンクと1クリック動画翻訳。クリエイターの個人ブランド動画に人気。

- **D-ID:** 1枚の写真を話す顔に。リアルタイムの「デジタルヒューマン」エージェントや API も。開発者・対話エージェント寄り。

### 各ツールの要点
- **Vrew（日本で特に人気）:** 音声を解析して**自動で字幕生成**。テキストから動画生成、AIナレーション（合成音声）、字幕の自動翻訳、無音区間の自動カットなど。台本/トピックを入れると、ストック素材・AI画像・AIナレーション・字幕付きのシーンを自動生成。無料枠は AI生成動画がダウンロード不可・冒頭に透かしあり（商用利用は規約要確認）。
- **InVideo AI:** プロンプト1つで台本＋素材＋ナレーション＋音楽＋トランジション付きの動画を数分で。2025年10月から **Sora 2 と Veo 3.1 を1つのサブスクに統合**。

## 4. 実際の制作ワークフロー（ここが核心）

### 4-1. 「画像ファースト」パイプライン（最も一般的）

> **コンセプト/台本 → 静止画生成 → 画像を動かす(image-to-video) → アップスケール → 音声＋音楽 → 編集 → 投稿**

1. **企画・台本（ChatGPT / Claude / Gemini）** … トレンド（Google Trends・X・TikTok）を拾い、60秒台本を作ってシーン分割。さらにシーンごとの「画像プロンプト」と「動き（モーション）プロンプト」まで LLM に出させる。
2. **最初の1フレームを静止画生成（Midjourney / Nano Banana / DALL·E / Stable Diffusion / Flux）** … 先に静止画で構図・キャラ・スタイルを固める。動画生成より安く速く反復できる。
3. **静止画を動かす（Kling / Runway / Hailuo / Luma / Midjourney V1）** … 画像を最初のフレームとして渡し、モーションプロンプトを入力。
4. **アップスケール → 素材として組み立て。**

**なぜ画像ファーストが強いか:** 静止画の段階で構図・キャラ・スタイルを完全にコントロールでき、その静止画が複数クリップ間の**一貫性のアンカー**になる。動画クレジットを浪費する前に方向性を固められる。

### 4-2. 「完成した1本のショート」パイプライン（音声・音楽・編集を足す）

1. **台本（ChatGPT/Claude/Gemini）** … トレンドから60秒のバズ台本。
2. **ナレーション（ElevenLabs）** … 台本を貼り、声/モデルを選び、stability・style スライダーを調整して生成・DL。
3. **音楽・効果音（Suno / Udio）** … 例:「アップビートな企業系BGM、90 BPM、歌詞なし、60秒」。商用可ティアに注意。
4. **映像** … 4-1のクリップ、またはシーンごとのストック/AI映像。
5. **編集・字幕（CapCut / Premiere / Descript）** … タイムラインで結合、トランジション、**自動字幕**（どのプラットフォームのアルゴリズムも字幕付きを優遇）。

### 4-3. キャラ・スタイルの一貫性を保つ技

**キャラ一貫性**
- Midjourney の `--cref`（キャラ参照）/ `--omniref`（V7、複数画像を同時参照。正面・全身・背面など）。きれいな正面ポートレートから始めるのがコツ。
- 「ビジュアルアンカー」として、キャラ参照・スタイル参照・構図参照・環境参照を使い分ける。
- **Nano Banana（Gemini の画像モデル）** で同一キャラを別ポーズ/別シーンに再配置してから動かす運用が定番。Nano Banana Pro は Google の Flow の既定画像モデル。

**スタイル一貫性**
- `--sref`（スタイル参照）で照明・配色・技法・全体の雰囲気を合わせる。既存シリーズの画像を `--sref` 元にするとキャラとスタイルを同時に固定。
- 気に入った見た目で `--seed` を固定し、小さく編集していく。変数（seed・構図・レンズ/焦点距離・アスペクト比）を固定するほど一貫する。

### 4-4. 動画モデルへのプロンプトのコツ（カメラ・ショット・モーション）

- **1プロンプト＝1ショット**。「被写体＋動作＋環境＋カメラの動き」を明確に。**主要なアクションは1つ**に絞る。
- **動き(モーション)を明示的に書く** … 動画モデルは動きを作るためのもの。「何が動くか／何を固定するか／カメラがどう振る舞うか」を書く。
- **カメラ用語**: pan / zoom / dolly / close-up / tracking / following など。Kling では「**カメラ指示はプロンプトの冒頭に置く**」と再現性が上がる、複雑な映画用語より単純で明確な指示が効く、という知見。
- **照明・雰囲気・スタイル**を指定（例: cinematic, golden hour lighting, dramatic）。不要要素は除外/ネガティブワードで落とす。生成を見ながら段階的に反復する。

## 5. バズっているジャンル別の作り方

### ① ASMR系（ガラスフルーツカット等）
- **見た目:** マクロ接写で「ガラスの果物」を切り、心地よい切断音。2025年6月頃から急拡大。
- **なぜ効く:** 「あり得ない満足感」=現実に存在しない音。
- **ツール:** Veo 3（映像＋音声を一括生成）via Google Flow。無料なら Veo＋MMAudio の組み合わせも。
- **定番プロンプト:**「A person slices up a {item} made of shiny glass. A hyper-realistic ASMR-style video, filmed with a macro lens on a stationary tripod, ultra-detailed textures, satisfying cutting sounds, cinematic lighting.」素材感（光沢のあるガラス、反射、内部ハイライト）、マクロ/浅い被写界深度、固定三脚、明確なスライス回数を指定。

### ② かわいい動物 / 偽「監視カメラ」動物クリップ
- **見た目:** 服を着た子ザル等のかわいい系、または夜間防犯カメラ風のフェイク映像（トランポリンのウサギ動画は TikTok で2.03億再生→AIと判明）。
- **ツール:** 主に Veo 3。プロンプト集が販売されている。
- **なぜ防犯カメラ風が効くか:** 低照度・粒状の「Ring カメラ」風がAIのアラを隠す。
- ⚠️ **最も物議を醸すジャンル。** 数百万人を騙し、「見分け方」の定石（指の数など）も通用しなくなっており、Washington Post や州の野生生物当局が誤情報・野生動物保護の観点で警告。

### ③ しゃべる赤ちゃん / ペットのミーム
- **見た目:** (a) 赤ちゃんがポッドキャスト風にしゃべる「AI baby podcast」、(b) 口を手で押さえて笑いをこらえ振動する「holding-laugh」ミーム（2025年11月頃〜）。
- **ツール:** 1枚の静止画を動かすリップシンク系（Lipsync.video 等）、専用「AI baby podcast」生成ツール。ミーム版はロトスコープ＋AIモーションフィルタ。写真1枚＋テキスト/音声で簡単に作れる。

### ④ POV歴史もの / 顔出しなし解説
- **見た目:**「POV: 90年AD のコロッセオで1デナリウス払う」のような一人称タイムトラベル。
- **ツール:** Sora が再現に使われる。縦型ショート。
- ⚠️ **信頼性に注意:** BBC は歴史家の「素人的で危険」という指摘を報道。エンゲージメント最適化の創作で、正確な歴史ではない。

### ⑤ 顔出しなしAIチャンネル（Reddit物語・歴史・実話怪談・教訓もの）
- **見た目:** ストック/AI映像/アバターにナレーションを載せ、顔は出さない。
- **ワークフロー:** ElevenLabs（音声）＋ Pictory 等。制作を約8時間→約20分に短縮との声。
- 💰 **収益化の主張:** 登録1万〜5万人で月$500〜2,000、5万〜20万人で月$2,000〜10,000 等。
- ⚠️ ただしこれら金額の多くは**教材販売者やブログ発で、誇張インセンティブあり**。鵜呑みにしない。

### ⑥ AI UGC風の商品広告（「AI広告」）
- **見た目:** 俳優も撮影もなしの「リアルな人が商品を語る」証言型広告。UGC風は作り込み広告の約4倍変換するとの主張。
- **ツール:** Sora 2（リアルさ・物語）、Kling（量・一貫性）、Veo 3.1（映画的4K B-roll）、Runway（スタイライズ）。商品写真1枚→UGC/シネマ広告。Sora 2 の「Trends」には Luxury Ad・Unboxing・ASMR 等のプリセット。
- **プロンプト:** 制作現場言葉（フレーミング＋カメラの動き、環境/照明、トーン/テンポ、画面上のコピー、ブランドカラー等の継続アンカー）。

### ⑦ AI音楽MV / AIミュージシャン / バーチャルインフルエンサー
- **見た目:** AIペルソナが実曲をリリース。Xania Monet（AIゴスペル/R&B、大型契約・チャートイン）、Breaking Rust「Walk My Walk」（Billboard チャート1位）等。
- **ツール:** Suno（主力、Suno Studio）、Udio。映像は Veo/Sora。
- **業界:** ワーナー等が2025年11月に Suno と和解・ライセンスへ。

### ⑧ AIインフルエンサー / バーチャルモデル
- **見た目:** 一貫した架空人格が週10〜20本リール投稿。Lil Miquela、Imma（日本）、Aitana Lopez 等。
- **ツール:** テキスト→画像＋顔一貫性付き image-to-video（HeyGen, Higgsfield, ZenCreator, フェイススワップ）。
- 💰 Instagram は2025年8月31日に Reels Play ボーナス終了 → 収益はサブスク(Fanvue)・アフィリエイト・ブランド案件へ。⚠️ 金額は自己申告・外れ値が多い。

## 6. 収益化とプラットフォーム規約の現実（重要）

「簡単に稼げる」論への最大のカウンターは**プラットフォームの取り締まり**です。

- **YouTube（2025年7月15日改定）:**「繰り返しコンテンツ」→「**水増し/非本物（inauthentic）コンテンツ**」へ呼称変更。テンプレ量産・自動ナレーションだけ等は収益化剥奪リスク。AI自体は禁止ではなく、**独自性＋人間の視点**が判断軸。
- **取り締まりは実在:** 2026年1月、YouTube がAIコンテンツ16チャンネルを一括停止（累計約47億再生）との報道。
- **Instagram:** Reels Play ボーナス終了（2025年8月31日）。閲覧数ベースの直接報酬は消え、サブスク/アフィリエイト/ブランド案件へ。

**結論:** 流通している「顔出しなしAIチャンネル/AIインフルエンサーで○○万円」系の収益額は、**教材販売者発がほとんど**で未検証。AIスロップの大量生産は今やむしろ収益化剥奪の標的。プラットフォーム自身が示す持続可能な路線は「**人間の独自ディレクションを伴うAI活用**」です。

## 7. はじめ方の推奨（目的別）

- **とにかくバズる実写級クリップを試したい:** ChatGPT Plus（Sora）か Google AI Pro（Veo 3.1）。まずは ASMR や動物などテンプレ的ジャンルで「画像ファースト」を試す。
- **顔出しなしで解説/物語チャンネル:** 台本(ChatGPT/Claude) → Vrew か CapCut で字幕付き自動生成 → ElevenLabs か VOICEVOX でナレーション → Suno で BGM。
- **自分（または分身）がしゃべる動画を量産:** HeyGen か Captions でデジタルツイン。
- **商品のUGC広告を量産:** Argil（自分のクローン＋商品実演）か Arcads（AI俳優）。
- **共通のコツ:** 最初の約3秒でフック、60秒以内、必ず字幕、縦型。台本の8割はAIに任せ、残り2割の「自分らしさ・独自視点」に注力する。

## 8. 全体の注意点・不確実性

- 価格・モデル名・機能は**毎月変動**（Sora 2、Veo 3.1、Kling 2.6、CapCut 2026料金改定など）。利用前に公式で要確認。
- 多くの**収益額・再生数は教材販売者やプレス発**で、誇張・チェリーピッキングの可能性。データではなくマーケティングとして読む。
- **偽動物/偽歴史ジャンルは誤情報リスクが現実的**（BBC・Washington Post・州当局が警告）。作る側も見る側も注意。
- 各社公式ページは自動取得をブロックしていることが多く、一部数値は二次情報ベース。重要な意思決定の前には一次情報で裏取りを。
